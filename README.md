# Micron Fencing Company - Website Content and Assets

Prepared 8 October 2026.

This pack brings together the website content, current logo exports, supporting brand materials and implementation notes from this project.

## Start here

1. Read `content/website-content.md` for the complete six-page website draft.
2. Use `assets/logos/` for the latest twisted-wire M with chain-link mesh.
3. Read `brand/current-brand-guide.md` for current logo, colour and typography usage.
4. Complete `content/data/business-details-template.json` and obtain the photographs listed in `handoff/image-requirements.md`.
5. Give `handoff/developer-handoff.md` to the website developer.

## Included

- Six page-by-page content files plus a combined copy document.
- FAQs, footer, contact form, error messages and calls to action.
- JSON versions of content, product information and SEO drafts.
- 11 SVG logos and 11 transparent PNG logos: horizontal, stacked and icon-only.
- A logo preview sheet and the latest concept presentation.
- Current brand usage guide, CSS design tokens and supporting fonts with licence.
- Original 18-page brand book, retained in the reference folder.
- Sitemap, asset map, image shot list and launch checklist.

## Current logo takes precedence

The original brand book predates the later logo iterations. Its strategy and broad colour direction remain useful reference material, but use the latest SVG/PNG artwork and the current brand guide for implementation. The outlined logo lettering is not the supporting DejaVu Sans font.

## Items still required from the business

Contact details, service areas, domain, business hours, confirmed product specifications and real project/product photography. Prices, warranties, certifications and experience figures have not been invented. Bracketed values and null JSON fields are deliberate placeholders.

This is a content and asset handoff pack, not a completed website codebase. Product photographs, favicon, social-preview image and a business-specific privacy policy are not included.
