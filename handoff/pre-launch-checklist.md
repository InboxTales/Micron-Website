# Pre-launch Checklist

## Business and content

- [ ] Complete phone, WhatsApp, email, address, hours, domain and service areas.
- [ ] Confirm product dimensions, GSM measurement basis and current availability.
- [ ] Confirm material-only supply and installation/servicing coverage.
- [ ] Replace every bracketed contact placeholder.
- [ ] Add actual product/site photography and accurate alt text.
- [ ] Review all page copy and draft SEO text with the business.
- [ ] Supply a privacy policy that matches the actual enquiry, analytics and upload handling.

## Brand and interface

- [ ] Use the current M, barbed wire and mesh logo throughout.
- [ ] Check logo detail at actual mobile, print and signage sizes.
- [ ] Confirm readable contrast, visible focus states and usable touch targets.
- [ ] Check mobile, tablet and desktop layouts.
- [ ] Verify the main CTA, all product enquiries, phone and WhatsApp links.

## Forms, SEO and performance

- [ ] Test enquiry success, server failure, validation and spam handling.
- [ ] Confirm optional image-upload limits and error messages.
- [ ] Keep credentials out of public code and assets.
- [ ] Use HTTPS and check all public links.
- [ ] Set titles, descriptions, canonical URLs, sitemap and robots rules.
- [ ] Create a suitably simplified favicon and social-preview graphic.
- [ ] Compress photographs and serve responsive sizes.
- [ ] Review font loading; convert supplied fonts to web-friendly formats if needed.
- [ ] Check page performance and accessibility on representative mobile devices.
- [ ] Test the custom 404 page and remove draft placeholders before launch.
