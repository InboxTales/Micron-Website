MICRON FENCING COMPANY - LOGO EXPORT PACK
=======================================
Latest selected concept: fence-post M, twisted barbed wire with sharp spikes,
and diamond chain-link mesh behind the M.

CONTENTS
11 SVG files + 11 transparent PNG files.
Horizontal, stacked and icon-only layouts.
A preview sheet is included for quick comparison.

COLOUR VERSIONS
charcoal: #171B1C artwork; intended for light or yellow backgrounds.
white: #FFFFFF artwork; intended for dark backgrounds.
yellow: #F4D62B artwork; intended for dark backgrounds.
brand: yellow symbol with white lettering; intended for dark backgrounds.
The brand icon is the same as the yellow icon, so it is not duplicated.

SVG
These are genuine path-based vectors traced from the latest concept image.
No embedded raster images, linked assets or required fonts.
The symbol, wordmark and descriptor are separately named vector groups.
Open in Illustrator, Figma or Inkscape to recolour or adjust paths.

PNG
All PNGs have real transparent backgrounds, including the spaces inside
letters, wire twists and mesh. White artwork may look blank in a white viewer.
Horizontal: 3200 pixels wide. Stacked: 2200 pixels wide.
Icon-only: 1600 x 1600 pixels.
PNG files are rendered from the matching SVG master.

USAGE
Use the horizontal layout for headers, documents and signs; the stacked
layout for centred compositions; and the icon-only file for compact spaces.
The detailed mesh is best used at medium and large sizes. Check visibility
at the intended size before applying it to very small marks or embroidery.
The SVG export preserves the concept's drawn geometry rather than replacing
its lettering with a different font. It is a vector trace, not a newly
engineered typographic master.
